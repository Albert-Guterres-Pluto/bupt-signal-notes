## 2. 图片引用方式

笔记位于 `笔记/<deck>/`，图片位于**根目录** `assets/`，两者相隔两层目录，
因此从笔记出发的相对路径必须是 **`../../assets/...`**：

```markdown
![图 2-1 矩形脉冲的频谱（课件 slide 51 / 第 51 页）](../../assets/slides21/page-0051.jpg)
```

- 图片目录：`C:\Users\29322\Desktop\学习资料\大二上课件\信号\assets\<slides01|slides21|slides22>\page-XXXX.jpg`
- 从 `笔记/<deck>/xxx.md` 出发的相对路径 = `../../assets/<dir>/page-XXXX.jpg`

> ⚠️ 历史坑：早期规范误写成 `../assets/`，它会解析到不存在的 `笔记/assets/`。
> 若发现笔记里存在 `../assets/`，运行 `python _tools\fix_img_paths.py` 一键归一化（幂等）。
>
> 另外两个交付前必跑的脚本：`python _tools\fix_table_pipes.py`（表格里的 `$|x(t)|$` 会破表）、
> `python _tools\verify.py`（插图/来源块/覆盖率综合校验）。
- **只嵌入真正有信息量的图**（波形图、频谱图、框图、公式推导图、表格截图）。
  纯文字页、纯标题页、目录页、装饰图一律不要嵌入。
- **估算：每个 deck 控制在 25–60 张插图**，宁少勿多。判断标准见下。

### 图片取舍：先问"这张图离开课件还有没有用"

用户的反馈（2026-10-07）值得每轮都遵守：

> 课堂演示都是动态的，直接贴一张静态图上去，怎么想都没有用。

| 情况 | 该不该放图 | 怎么处理 |
|---|---|---|
| 交互演示页（滑块、动画、播放控件） | **不放** | 写一两行"演示了什么现象 → 结论是什么"；结论能用公式表达就用 LaTeX |
| 演示页的**静态图形本身就是结论**（如单边谱 vs 双边谱、时宽频宽反比） | 放 | 这就是复现结论最省事的方式 |
| 截图内容与正文 LaTeX **重复**，图里没有波形/曲线/框图 | **不放** | 正文 LaTeX 已够，图只是占地方 |
| 推导连贴 3–4 张（分析/性质/证明/结果） | 只放**带结论的最后一张** | 中间步骤用文字+公式讲 |
| 波形、频谱、框图、对比图、汇总表 | 放 | 这是笔记里最值钱的部分 |
| 目录页、章节封面页、纯标题页 | **不放** | 零信息 |

### 文字密度：笔记不是课件搬家

- **不要同时写"本章要解决的问题"和"核心结论速查"**——内容必然重复。只留 `## 核心结论速查`（考前直接看），
  上面配 ≤2 句导语。
- **删掉元叙述**："本页介绍了…""课件展示了…""需要注意的是…"一律去掉，直接讲知识。
- **压掉铺陈**：口号、形容词、行业愿景压成表格或一行一条；只留可考事实（数值、比例、标准名、年份）。
- **目标密度**：一章读下来应当能回答"要记住什么、怎么用、坑在哪"，而不是"课件每页讲了什么"。
- 自测题每章 ≤5 题。

## 3. 笔记文件结构

每个文件开头固定：

```markdown
# <标题>

> **来源**：《信号分析与处理》<课件文件名>，第 X–Y 页（共 N 页）
> **对应课件章节**：<如 2.1.2.1 几何变换>

（≤2 句导语：这一章解决什么问题）

## 核心结论速查
（表格或短列表：公式 / 名称 / 适用条件 / 一句话说明）

---

## <小节标题>
（正文 + 插图）
```

结尾（可选但推荐）：

```markdown
## 易错点与考点提示
- ...

## 自测
1. ...
<details><summary>参考答案</summary>

...

</details>
```

## 4. 内容要求

1. **忠实于课件**：不得编造课件里没有的结论、数值、公式。课件没讲清楚的地方，宁可写「课件此处为演示，未给推导」。
2. **公式**：保留课件原有符号体系（如 `Ω₀`、`F_k`、`Sa(x)`、`sinc`），
   关键公式同时给 ① LaTeX 行间公式 和 ② 课件截图，方便对不上符号时看原图。
3. **备注（[备注]）不要丢**：那是老师口述的补充说明，往往就是考点，用 `> 课堂补充：…` 引用。
4. **表格**：课件里的表格要么用 markdown 表格重排，要么截图嵌入；长表格重排更好。
5. **课堂演示页**（"课堂演示：" 开头）要写清楚演示了什么现象、结论是什么。
6. **工程案例**（如「案例1：音频系统的回声」）单独成节，写清问题→方法→结论。
7. 语言：简体中文，工科教材语气；术语首次出现给出英文/符号（如 单位冲激信号 δ(t), unit impulse）。
8. 不要写"本页介绍了…""课件展示了…"这类元叙述；直接讲知识本身。

## 5. 图表/公式可用符号

- 卷积：`*`，写清是卷积还是乘法
- 傅里叶变换对：`x(t) ↔ X(Ω)`
- 单位：秒 s、弧度/秒 rad/s、赫兹 Hz
