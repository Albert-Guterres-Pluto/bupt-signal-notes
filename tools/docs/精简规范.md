# 笔记精简规范（本轮修订，所有精简者必须遵守）

目标：把笔记从「课件搬家」改成「能复习的笔记」——**留下知识与方法，删掉冗余与无效截图**。
质量口径：一个已经上过课、想考前复习的人，读完一章应当知道**要记住什么、怎么用、坑在哪**。

---

## 一、绝对不许删（信息完整性红线）

1. 所有**定义**（信号的、系统的、变换的、各种性质的适用条件）。
2. 所有**公式**及其适用条件、参数的取值范围。
3. 所有**性质/定理**的表述（含成立条件，如"$a$ 为非零实常数"）。
4. 所有**例题的题面与解题步骤**（可以压缩叙述，但推导链路不能断）。
5. 所有**易错点、使用条件、注意事项**。
6. 每章开头 `> 来源：《课件名》，第 X–Y 页` 元信息块（连页码一起保留，便于回查）。
7. 课件**备注**里的实质内容（`> 课堂补充：`），纯 URL 的备注可只留一句"备注给出延伸阅读"。

## 二、图片取舍规则（本轮重点）

### 必须删

| 类型 | 判据 | 处理 |
|---|---|---|
| **静态化后无信息的交互演示页** | 图里是滑块/按钮/播放控件，或整页只有一处波形 | **删图**，改写成一两行"演示结论"，必要时用 LaTeX 写结论 |
| **纯公式截图** | 图的内容与正文 LaTeX **重复**，且不含波形/曲线/框图 | **删图**，保留正文 LaTeX |
| **目录页、章节封面页、纯文字页** | 图上只有标题或几行文字 | **删图** |
| **与相邻图重复** | 同一推导连贴 3–4 张（如"分析/性质/证明/结果"） | 只留**最后一张带结论的** |

### 必须留

| 类型 | 例子 |
|---|---|
| **波形图 / 频谱图** | 冲激、阶跃、Sa、矩形脉冲频谱、周期矩形脉冲的离散谱线 |
| **概念示意图** | 抽样与量化、时域↔频域对偶、频谱搬移前后对比 |
| **系统框图 / 处理链路** | 传输系统框图、ISP 流程、自适应滤波链路 |
| **推导中的关键一步** | 分段讨论的图形、卷积图解法的关键帧（其余步骤用文字/公式） |
| **性质汇总表 / 变换对表** | 傅里叶变换性质汇总、典型非周期信号变换对汇总 |
| **动态演示中"结论本身是图"的页** | 例如单边谱 vs 双边谱对比、时宽频宽反比——这类页的静态图就是结论 |

### 图片写法

- 图注保持一行，写清"这张图要说明什么"，不要写"课件第 N 页的图"这种废话（页码已在来源块里）。
- 删图后**必须**保证该处知识仍然完整：能写成一句话的就写一句话，不要留下"（见图）"。

## 三、文字精简规则

1. **删掉"本章要解决的问题"与"核心结论速查"的重复**：二者只留一个。
   建议保留 `## 核心结论速查`（表格式，考前直接看），把"要解决的问题"压缩进它上面的一句话导语（≤2 句）。
2. **删掉元叙述**："本页介绍了……""课件展示了……""需要注意的是……"一律去掉，直接说知识。
3. **合并同义重复**：同一结论在多处出现时，只在最相关处详述，其余地方一句话带过。
4. **压缩排比与铺陈**：课件里"六个层面""五大领域"这类 motivational 内容，压成表格或一行一条，
   删掉形容词与口号（保留可考的事实：年份、数值、标准名、比例）。
5. **自测题**：每章最多保留 **3–5 题**，删掉送分题；`<details>` 答案保留。
6. **不要为了短而丢逻辑**：公式之间的"因为…所以…"链条保留。

## 四、目标量

- 每章正文字数 **减少约 1/3**（删图腾出的篇幅不算在内）。
- 插图总数 270 → **约 140–160**。
- 图片一删，`assets/` 里对应文件若不再被任何笔记引用，**本轮先不删文件**（保留以防回退），只改笔记。

## 五、交付前自检（必须全绿）

```powershell
python _tools\fix_img_paths.py
python _tools\fix_table_pipes.py
python _tools\verify.py            # 覆盖率不得出现缺口
python _tools\verify_captions.py
python _tools\scan_text.py
```

- `verify.py` 的**覆盖台账不能出现缺口**（删图不影响页码覆盖，来源块的页码范围必须原样保留）。
- 逐章核对：删图的位置**没有留下悬空引用**（如"如图所示"却无图）。
- 不许出现 `<待补充>`、`TODO`、空小节标题。
