# 《信号分析与处理》课程笔记

北京邮电大学《信号分析与处理》（80 学时 / 5 学分）课程课件整理笔记。
覆盖三份课件共 **361 张幻灯片**，每份笔记都标注来源课件与页码，可随时回到原课件核对。

> 这不是课件的搬运。整理时按"**复习用**"取舍：只保留能带走的知识与能对着复现的图，
> 砍掉了动态演示的静态截图、与正文重复的公式截图、以及大段口号式铺陈。
> 详细取舍原则见 [笔记的取舍原则](#笔记的取舍原则)。

### 完整笔记里有什么

- 每章以「导语（≤2 句）+ 核心结论速查表 + 逐节正文」组织；
- 关键公式给 LaTeX；**只在该图提供额外信息时**才配课件截图（波形、频谱、框图、对比图、汇总表）；
- 老师课上口述的内容以 `> 课堂补充：` 标出；
- 交互演示页（幻灯片里是滑块/动画的那种）**不贴截图**，只写一行"演示了什么 → 结论是什么"；
- 每章结尾有「易错点与考点提示」与「自测」（答案折叠在 `<details>` 里）。

## 提交前请跑一遍校验

只需要 Python 3（无需安装任何第三方包）：

```bash
python tools/check_all.py
```

它会检查：

1. **覆盖完整性**：各章声明的页码范围并集是否覆盖全部幻灯片（缺口 / 重叠）；
2. **插图**：链接是否真实存在、路径是否为 `../../images/slidesNN/page-XXXX.jpg`、页码是否越界；
3. **插图说明**：`课件 slide N / 第 P 页` 的映射是否与课件页数、隐藏页一致；
4. **结构与文本**：来源块、一级标题、markdown 表格列数、裸管道符、占位符、异常重复字。

全绿才提 PR。CI 会在 push / PR 时自动跑同一套检查。

## 参与贡献

欢迎补错、补漏、补图。几点约定（详见 [CONTRIBUTING.md](CONTRIBUTING.md)）：

- **不要改课件本身**：仓库里不含 pptx（体积原因，见下），笔记内容以课件为准；
- **页码一定要对**：插图说明里的"第 P 页"是**渲染图页码**，与幻灯片序号可能不同（部分课件有隐藏页）；
- **图宁少勿多**：能一句话讲清的不要配图；交互演示页不要贴静态截图；
- **不要删三类内容**：定义与公式（含适用条件）、例题的题面与解题链路、易错点。

## 笔记的取舍原则

1. **图只留"离开课件还有用"的**：波形图、频谱图、框图、对比图、性质/变换对汇总表。
2. **交互演示页不放截图**。原来那些滑块、动画，贴一张静态图毫无意义——
   只在正文写一行"演示了什么现象 → 结论是什么"。
3. **截图与正文公式重复的，删图留公式**；同一推导连贴多张的，只留带结论的那张。
4. **不写"本页介绍了…"这类元叙述**；口号、行业愿景压成表格，只留可考事实（数值、比例、标准名）。
5. **课件未单列的内容标明是推论**。例如傅里叶变换对表里"双边指数"一行标注了
   `（推论，课件未单列）`——它在课件里只作为符号函数逼近的中间步骤出现。凡是这种，一律标明来源。

精简成效：插图 270 → 133，叙述文字约减 1/3，**公式、性质、例题链路一步未动**
（用 `tools/compare_trim.py` 与 `tools/audit_lost_formulas.py` 逐条比对过公式指纹，零丢失）。

## 关于课件文件

仓库**不包含**原始的 pptx 课件（`01` 60 MB、`2.2` 51 MB，超过 GitHub 单文件 100 MB 限制，
也不适合公开分发课程材料）。因此：

- 笔记与插图是自包含的，`images/` 下已放好笔记引用的全部 133 张截图，**看图不受影响**；
- 若你手上有课件，想重新提取文字、渲染全部幻灯片或重新生成笔记，参见
  [tools/docs/更新方法.md](tools/docs/更新方法.md)；
- `tools/extract.py`、`formulas.py` 等脚本需要课件才能运行，缺少课件时跳过即可——
  日常提交只需 `check_all.py` 通过。

## 已知限制

- **公式的文字提取受课件限制**：2.1 节的公式是 OMML（可提取并转 LaTeX）；
  01 与 2.2 节的公式是 **MathType 对象**，只能留存图片。
  因此这些页面的公式以**课件截图为准**，笔记里的 LaTeX 仅作辅助排版，符号不一致时以截图为准。
- **内嵌 H5 演示页**静态导出后只有空白占位框，无法承载演示信息，笔记中不贴图、只写结论。
- 部分课件有**隐藏页**（不导出）：2.1 节隐藏 46/47/48，2.2 节隐藏 12/13/48，
  因此渲染图页码 ≠ 幻灯片序号，换算规则见各篇索引。
