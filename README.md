# 《信号分析与处理》课程笔记

北京邮电大学《信号分析与处理》（80 学时 / 5 学分）课程课件整理笔记。
覆盖六份课件共 **702 张幻灯片**，每份笔记都标注来源课件与页码，可随时回到原课件核对。

> 这不是课件的搬运。整理时按"**复习用**"取舍：只保留能带走的知识与能对着复现的图，
> 砍掉了动态演示的静态截图、与正文重复的公式截图、以及大段口号式铺陈。

### 完整笔记里有什么

- 每章以「导语（≤2 句）+ 核心结论速查表 + 逐节正文」组织；
- 关键公式给 LaTeX；**只在该图提供额外信息时**才配课件截图（波形、频谱、框图、对比图、汇总表）；
- 老师课上口述的内容以 `> 课堂补充：` 标出；
- 交互演示页（幻灯片里是滑块/动画的那种）**不贴截图**，只写一行"演示了什么 → 结论是什么"；
- 每章结尾有「易错点与考点提示」与「自测」（答案折叠在 `<details>` 里）。

## 提交前请跑一遍校验

只需要 Python 3（无需安装任何第三方包）：

```bash
python tools/check_all.py
```

它会检查：覆盖率（各章页码并集 = 全部幻灯片、无缺口无重叠）、插图链接与页码、
插图说明的 slide↔page 映射、来源块、表格列数、文本损坏、抱佛脚版纯净度（无例题/无图）。

全绿才提 PR。CI 会在 push / PR 时自动跑同一套检查。

## 参与贡献

欢迎补错、补漏、补图。约定详见 [CONTRIBUTING.md](CONTRIBUTING.md)：

- **页码一定要对**：插图说明里的"第 P 页"是**渲染图页码**，与幻灯片序号可能不同（部分课件有隐藏页）；
- **图宁少勿多**：能一句话讲清的不要配图；交互演示页不要贴静态截图；
- **不要删三类内容**：定义与公式（含适用条件）、例题的题面与解题链路、易错点；
- **课件未单列的内容标明是推论**（例如变换对表里的"双边指数"标了"课件未单列"）。

## 笔记的取舍原则

1. **图只留"离开课件还有用"的**：波形图、频谱图、框图、对比图、性质/变换对汇总表。
2. **交互演示页不放截图**。只在正文写一行"演示了什么现象 → 结论是什么"。
3. **截图与正文公式重复的，删图留公式**；同一推导连贴多张的，只留带结论的那张。
4. **不写元叙述**；口号、行业愿景压成表格，只留可考事实。
5. **课件未单列的内容标明是推论**。

## 关于课件文件

仓库**不包含**原始 pptx 课件（`01` 60 MB、`2.2` 51 MB，超过 GitHub 单文件 100 MB 限制，
也不适合公开分发课程材料）。笔记与插图是自包含的，`images/` 下已放好全部被引用的截图。

若你手上有课件，想重新提取文字、渲染全部幻灯片或重新生成笔记，参见
[tools/docs/更新方法.md](tools/docs/更新方法.md)。

## 已知限制

- **公式的文字提取受课件限制**：部分课件的公式是 OMML（可提取并转 LaTeX）；
  另一些是 **MathType 对象**，只能留存图片。因此这些页的公式以**课件截图为准**。
- **内嵌 H5 演示页**静态导出后只有空白占位框，笔记中不贴图、只写结论。
- 部分课件有**隐藏页**，因此渲染图页码 ≠ 幻灯片序号，换算规则见各篇索引
  （绪论无隐藏页；2.1 节隐藏 46/47/48；2.2 节隐藏 60）。
