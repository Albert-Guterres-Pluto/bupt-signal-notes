## 符号约定（本部分统一使用）

| 符号 | 含义 |
|---|---|
| $T_0$ | 周期信号的周期（2.2.4 节课件改用 $T$） |
| $\Omega_0=\dfrac{2\pi}{T_0}$ | 基波角频率（基频） |
| $a_0,a_n,b_n$ | 三角函数形式傅里叶级数系数 |
| $c_0,c_n,\varphi_n$ | 谐波（余弦）形式傅里叶级数系数与初相 |
| $F_n$（或 $F_k$） | 指数形式傅里叶级数系数，即周期信号的频谱 |
| $\mathrm{Sa}(x)=\dfrac{\sin x}{x}$ | 抽样函数 |
| $X(\Omega)$、$F(\Omega)$、$F(\mathrm{j}\Omega)$ | 非周期信号的频谱密度函数（傅里叶变换） |
| $\delta(t)$、$\delta(\Omega)$ | 单位冲激函数 |
| $u(t)$、$\mathrm{sgn}(t)$ | 单位阶跃函数、符号函数 |
| $*$ | 卷积（本文中乘法一律用「·」或并列，避免与卷积混淆） |
| $\mathrm{F}[\cdot]$、$\mathscr{F}[\cdot]$ | 傅里叶正变换算子 |
