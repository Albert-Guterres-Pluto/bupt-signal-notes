## 符号约定

| 符号 | 含义 |
|---|---|
| $s=\sigma+\mathrm{j}\Omega$ | 复频率；$\sigma$ 为实部（待定实常数），$\Omega$ 为虚部角频率 |
| $\mathscr{L}\{\cdot\}$、$\mathscr{L}^{-1}\{\cdot\}$ | 双边拉氏正变换、逆变换算子 |
| $\mathscr{L}_+\{\cdot\}$ | 单边拉普拉斯变换（积分下限 $0^{-}$） |
| $x(t)\leftrightarrow X(s)$ | 拉氏变换对的简写 |
| ROC | 收敛域，$X(s)$ 存在的 $s$ 的取值范围；$R_x$、$R_1$、$R_2$ 为对应信号的 ROC |
| $\gamma$ | 逆变换积分路径的实横坐标，须取在 ROC 内 |
| $u(t)$、$\delta(t)$、$\delta^{(k)}(t)$ | 单位阶跃、单位冲激、冲激的 $k$ 阶导数 |
| $p_i$、$z_j$ | $X(s)$ 的极点（画 ×）、零点（画 ○） |
| $*$ | 卷积（乘法一律用「·」或并列写出，避免混淆） |
| $\mathrm{PV}$ | 柯西主值（虚轴极点的广义傅氏变换中出现的积分主值） |

## 建议阅读顺序

1. **先 01**：弄清 $s=\sigma+\mathrm{j}\Omega$ 的由来，以及为什么必须写 ROC；
2. **再 02、03**：性质与变换对是后面的计算弹药，边读边默写表；
3. **然后 04**：逆变换是本章唯一计算大题，按"判真假分式 → 展开 → 用 ROC 定时域项"三步练；
4. **05 只考判断**（虚轴在不在 ROC 内），**06 用来考前自检**。
